# Поезд-кликер (train_game)

Кликер на pygame. Десктопная версия — `game.py`; мобильная собирается в
**офлайн-APK** через pygbag (pygame → WebAssembly) и упаковку в Android-APK
без Gradle.

## Структура

| Путь | Что это |
|---|---|
| `game.py` | точка входа: окно, масштаб, ассеты, сущности и главный цикл |
| `progression.py` | мета-прогресс: перерождения, чертежи, дерево, реликвии, контракты, достижения |
| `prog_ui.py` | тонкий реэкспорт `taran/ui/hud.py` для старых вызовов |
| `taran/config.py` | статические данные: темы, боссы, улучшения, предметы, скины, геометрия |
| `taran/logic.py` | чистые расчёты: цены, инфляция, пороги, выбор публики |
| `taran/saves.py` | чтение и запись `save.json` с миграцией старых сейвов |
| `taran/audio.py` | `SoundKit`: эффекты и музыка |
| `taran/world.py` | `World`: небо, город, платформа, пути, погода |
| `taran/train.py` | спрайт состава и `Train` |
| `taran/effects.py` | частицы, всплывающий текст, монеты, кровь, череп, кислота |
| `taran/creatures.py` | спрайты боссов-зверей (от голубя до дракона) |
| `taran/assets.py` | виньетка, конусы света, тени, череп, кислота, фон магазина |
| `taran/ui/theme.py` | единая палитра интерфейса |
| `taran/ui/shop.py` | панель «Мастерская» (магазин справа) |
| `taran/ui/hud.py` | HUD рейса, сердца, кнопка звука, полоса босса, экран «Депо» |
| `ARCHITECTURE.md` | карта модулей и план следующих этапов рефакторинга |
| `intro_frames/` | кадры заставки |
| `test_smoke.py` | дымовой тест десктопной логики |
| `_meta_test.py` | тест мета-прогресса (перерождение, дерево, реликвии) |
| `mobile/` | весь пайплайн мобильной сборки |
| `mobile/make_mobile.py` | патчит `game.py` под веб → `mobile/game_app.py` |
| `mobile/rebuild.py` | сборка APK одной командой |
| `mobile/build_apk.py` | упаковка и подпись APK (aapt2/d8/apksigner) |
| `mobile/setup.py` | проверка/докачка инструментов (`--fetch`) |
| `apk/` | AndroidManifest, MainActivity, иконка |
| `pygbag.ini` | что НЕ паковать в архив игры |

Каталоги `android_sdk/`, `.apkbuild/`, `packages/`, `mobile/cdn_cache/`,
`mobile/build/` в git не входят — они восстанавливаются (см. ниже).

## Что нового в 3.2

- **Единый современный интерфейс:** глубокая тёмная палитра, спокойные карточки
  с тонкими рамками и крупные цифры. HUD, магазин и «Депо» теперь выглядят как
  одна система, а не три разных экрана.
- **HUD разбит на три зоны:** баланс и доход слева, рейс и маршрут в центре,
  чертежи/ранг/достижения и кнопка «Депо» справа. Зоны разделены тонкими
  линиями, ничего не наезжает друг на друга.
- **Магазин переработан:** сегментированные вкладки с цветом раздела и точкой
  «есть что купить», уровень в бейдже, цена в «пилюле», тонкий прогресс-бар.
- **Быстрая покупка:** `Shift` + клик покупает до 10 уровней сразу.
- **Депо:** навигация получила клавиши `1–4`, карточки дерева/реликвий/
  контрактов/достижений перерисованы в общем стиле, подсказки стали короче.
- **Мелочи:** кнопки звука и паузы выровнены с «Депо», подсказки внизу не
  обрезаются, панель «Депо» больше не просвечивает HUD.

## Что нового в 3.1

- **Дерево выросло до 27 узлов:** по 9 на каждую ветку, добавлены два ряда
  новых навыков (сейвы 3.0 открывают их сразу, миграция автоматическая).
- **Тяга:** «Щедрые чаевые» (+15% за уровень к монетам) и «Премия за рейс»
  (+1 чертёж за каждые 5 пройденных станций при перерождении).
- **Броня:** «Точный расчёт» (+25% за уровень к урону крита, база x3) и
  «Второе дыхание» — один раз за рейс забег в хардкоре не сбрасывается.
- **Логистика:** «Плотная посадка» (+1 место на платформе за уровень) и
  «Разгон» (час пик длится дольше и приходит чаще).
- Сетка дерева уплотнена (9 рядов по 49 px), все карточки влезают в панель.
- **Компактный тост сверху:** сообщения больше не закрывают центр сцены и не
  спорят с баннером станции; длинный текст аккуратно обрезается.
- **Депо на весь экран:** панель перекрывает HUD и подсказки по краям, внизу
  появилась сводка по вкладке (прогресс, награда, собрано реликвий).
- **Вкладки Депо доработаны:** контракты получили итоговую карточку и проценты
  прогресса, реликвии — карточку следующей награды, достижения — общий прогресс
  и награду «+1 ЧТ» в каждой строке.
- **Магазин:** шапка с инфляцией и чертежами разложена в две аккуратные
  «пилюли», ничего не наезжает и не обрезается.
- **Оптимизация:** кадр масштабируется в переиспользуемый буфер (без новой
  поверхности каждый кадр), сердечки жизней кэшируются, кэш спрайтов реже
  очищается, число одновременных всплывающих эффектов ограничено.
- **Модульная архитектура:** логика, сейвы, звук, мир, поезд, эффекты, спрайты
  боссов и оба UI-модуля вынесены в пакет `taran/`. `game.py` остался точкой
  входа и по-прежнему реэкспортирует старые имена, поэтому сейвы, тесты и
  мобильная сборка работают без изменений. Карта модулей — в `ARCHITECTURE.md`.

## Что нового в 3.0

- **Перерождение вместо тупика на 20 станциях.** После 10-й станции (или победы)

- **Дерево чертежей:** 21 узел в трёх ветках (Тяга / Броня / Логистика) —

- **Реликвии:** после перерождения выбирается 1 из 3; всего 12, бонусы
  сохраняются между забегами.
- **Контракты и 24 достижения** дают дополнительные чертежи за конкретные цели.
- **Модификаторы рейса** меняют правила каждого нового цикла, а боссы и доход
  растут вместе с числом перерождений.
- **Офлайн-доход** начисляется за время вне игры, есть автотолчок и автозакупка.
- Новый HUD показывает сегмент маршрута, серию, чертежи и готовность к

## Веб-версия и установка с сайта (PWA)

`py mobile/rebuild.py` собирает и веб, и APK. Если APK не нужен, достаточно:

```bash
py mobile/make_mobile.py       # патч game.py -> mobile/game_app.py
py mobile/prepare_offline.py   # локальный рантайм вместо CDN pygbag
py mobile/make_pwa.py          # манифест, иконки, service worker
py mobile/serve_web.py 8099    # посмотреть: http://127.0.0.1:8099/
```

Готовый каталог — `mobile/build/web` (~45 МБ, из них ~23 МБ рантайм и игра).

Что даёт PWA-слой (`mobile/pwa/` + `mobile/make_pwa.py`):

- **установка с сайта:** на Android — «Установить приложение» в Chrome, на
  iPhone (iOS 26+) — «Поделиться → На экран Домой» (подсказка показывается сама);
- **офлайн:** service worker кэширует страницу, рантайм, шрифты и `mobile.apk`,
  после первого запуска игра стартует без сети (проверено с выключенным сервером);
- **обновления:** версия кэша берётся из `versionName` манифеста, при новой
  сборке появляется кнопка «Обновить»;
- `warm.json` — список файлов рантайма, которые грузятся раньше, чем SW берёт
  страницу под контроль; их догружает сам worker в фоне.

Требования к хостингу: **HTTPS**, MIME `.wasm` → `application/wasm`,
`.webmanifest` → `application/manifest+json`, длинный `Cache-Control` на `/cdn/`,
сжатие gzip/brotli. Заголовки `Cross-Origin-Opener-Policy: same-origin` и
`Cross-Origin-Embedder-Policy: require-corp` нужны как в `serve_web.py` —
без них часть сборок pygbag стартует медленнее. Подойдёт любой статический
хостинг (Cloudflare Pages, Netlify, Vercel, GitHub Pages с HTTPS).

## Сборка APK

Нужен Python 3.12+ (`py`), интернет — только при первой настройке:

```bash
py mobile/setup.py --fetch   # один раз: JDK, build-tools, рантайм pygbag
py mobile/rebuild.py         # полная сборка -> mobile/build/TaranExpress_v3.2.apk
```

Готовый APK: `mobile/build/TaranExpress_v3.2.apk` (~33 МБ). Ставится на телефон
обычной копией файла (разрешение «установка из неизвестных источников»).
Игра работает **полностью офлайн**: CPython-WASM, pygame и все ассеты лежат
внутри APK, внешних запросов нет.

APK подписан самоподписанным debug-ключом (`android_sdk/debug.keystore`) —
для себя/друзей этого достаточно, для Google Play нужен выпускной ключ.

## Публикация в Google Play (кратко)

1. Аккаунт разработчика Play Console — $25 разово, верификация личности.
2. Play принимает только **`.aab`** (Android App Bundle), не APK.
3. `targetSdkVersion` для новых приложений — **36** (Android 16); сейчас в
   сборке 33, поэтому перед публикацией надо поднять `--target-sdk-version`
   в `mobile/build_apk.py` и положить `android_sdk/platform` версии 36.
4. Нужны: приватная политика (ссылка в магазине и в приложении), форма
   «Безопасность данных», рейтинг IARC, 64-bit (у нас нет нативных библиотек —
   выполняется автоматически).
5. Для личного аккаунта перед выходом в прод — закрытое тестирование:
   12 тестировщиков, 14 дней подряд.
6. Подписи: Play App Signing — Google хранит выпускной ключ, первый `.aab`
   подписывается вашим ключом (`keytool -genkeypair`), дальше Play сам
   подписывает выдаваемые APK.
