# Документация «ТАРАН-ЭКСПРЕСС» 3.2

Полный комплект проектной документации по игре: общие сведения, требования,
спецификации, архитектура со схемами, процесс разработки, тестирование с реестром
дефектов и презентация для защиты.

Всё содержимое собрано по реальному коду версии 3.2: цифры контента берутся из
`taran/config.py` и `progression.py`, схемы и графики рисуются скриптами из `_tools/`,
статусы тестов — из фактических прогонов 9 ноября 2026.

## Как открыть в Google Докс и Google Презентациях

Документы сделаны в `.docx` и `.pptx` — форматах, которые Google Диск открывает
как Google Документы и Google Презентации с сохранением заголовков, таблиц,
рисунков и заметок докладчика.

### Вариант 1. Загрузить папку целиком (рекомендуется)

1. Откройте [Google Диск](https://drive.google.com) и создайте папку, например
   «ТАРАН-ЭКСПРЕСС — документация».
2. Перетащите в неё папку `docs` из проекта. Диск спросит про структуру —
   выберите **«Загрузить папку»**, чтобы подпапки сохранились.
3. Дождитесь окончания загрузки (около 4 МБ, 20+ файлов).
4. Для каждого `.docx`: правый клик → **«Открыть с помощью» → «Google Документы»**.
   Для `.pptx`: **«Google Презентации»**.
5. В открывшемся документе: **Файл → Сохранить как Google Документ**
   (для презентации — «Сохранить как Google Презентации»). После этого файл
   станет полноценным Google Документом, а `.docx` можно удалить.
6. Проверьте оглавление: заголовки разделов уже размечены стилями, поэтому
   в Google Документах работает панель «Структура документа» и вставка
   автоматического оглавления (**Вставка → Оглавление**).

### Вариант 2. По одному документу

1. На Диске: **Создать → Загрузить файлы**.
2. Правый клик по файлу → **«Открыть с помощью» → «Google Документы»**.
3. **Файл → Сохранить как Google Документ**.

### Импорт презентации

1. Загрузите `10_Презентация_ТАРАН-ЭКСПРЕСС.pptx`.
2. Правый клик → **«Открыть с помощью» → «Google Презентации»**.
3. **Файл → Сохранить как Google Презентации**.
4. Проверьте шрифт: слайды используют Segoe UI. Если его нет, Google подставит
   Arial — вёрстка не поедет, но межстрочные интервалы немного изменятся.
   При желании: **Формат → Заменить шрифты**.
5. Заметки докладчика переносятся: они в каждом слайде, откройте панель
   «Заметки докладчика».

### Ссылка для преподавателя

1. В Google Диске откройте папку с документами.
2. **Поделиться → Доступ по ссылке → «Читатель»** → скопировать ссылку.
3. Эту ссылку и отправляйте: в папке будут все документы, схемы и презентация.

## Как пересобрать документацию

Все скрипты лежат в `docs/_tools/` и запускаются из корня проекта:

```bash
py docs/_tools/schemes.py        # 8 схем → docs/04_Архитектура/схемы
py docs/_tools/charts.py         # 6 графиков → docs/материалы
py docs/_tools/build_docs.py     # 9 документов .docx
py docs/_tools/build_deck.py     # презентация .pptx
py docs/_tools/check_docs.py     # проверка структуры документов
py docs/_tools/deck_check.py docs/07_Презентация/10_Презентация_ТАРАН-ЭКСПРЕСС.pptx
```

Требуются `python-docx`, `python-pptx`, `Pillow` и `pygame-ce` (последний уже есть
в проекте). Схемы рисуются в палитре интерфейса игры, поэтому документация и игра
выглядят как одна система.

## Честные ограничения

- **Юзабилити-сессии не проводились.** В документе 07 есть методика, протокол,
  метрики и шаблон таблицы; в документе 08 соответствующие тест-кейсы помечены
  как «запланированы». Придуманных отзывов игроков в документах нет.
- **Ручные проверки на телефоне и хостинге (TC-24…TC-28) ещё не выполнены** —
  для них нужны устройство и HTTPS-хостинг.
- **Единственный открытый дефект BR-12** — `targetSdk 33` при требовании
  Google Play 36. Установка APK вручную работает, публикация в магазине — нет.
- **Замер FPS сделан headless** (SDL dummy): он показывает относительную стоимость
  кадра, а не реальный FPS на видеокарте.
- **Оформление `.pptx` проверено геометрически** (границы слайда, переполнение
  текстовых блоков), но не отрендерено в PowerPoint или LibreOffice — на этой
  машине их нет. Первый импорт в Google Презентации стоит просмотреть глазами.
- Документы используют шрифт Arial для текста и Consolas для кода: они есть
  в Google Документах и не требуют установки.
